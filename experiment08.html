Experiment 8: Create Web page for Student Profile Card: design layouts using flexbox (justify-content, align-items, flex direction). Objective: To design layouts using flexbox (justify-content, align-items, flex-direction). Tools Required • Text Editor (Notepad, VS Code, Sublime Text) • Web Browser (Chrome, Edge, Firefox) Theory: Flexbox (Flexible Box Layout) is a CSS layout model that allows easy alignment and distribution of elements inside a container. It is especially useful for responsive design. Key properties: 1. display: flex; → Defines a flex container. 2. flex-direction: o row → Items placed left to right (default). o column → Items placed top to bottom. o row-reverse / column-reverse → Reverse order. 3. justify-content: (aligns items on the main axis) o flex-start → Items at the beginning. o center → Items centered. o flex-end → Items at the end. o space-between, space-around, space-evenly → Distributes space. 4. align-items: (aligns items on the cross axis) o flex-start, center, flex-end, stretch, baseline. 5. flex-wrap: → Moves items to the next line if space is insufficient. In this experiment, we apply flexbox to arrange multiple student profile cards neatly. Code Implementation Student Profile Cards

Output:

Three student profile cards arranged in a row, aligned at the center of the page.
